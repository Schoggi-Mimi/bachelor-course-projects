# Applied Machine Learning in Medicine Coursework

This folder collects several practical assignments from an applied machine learning in medicine course, including ECG classification, skin lesion dataset analysis, sepsis-related experiments, and medical image classification exercises.

## Overview
- Coursework archive from a medical AI / applied ML module
- Includes multiple smaller assignments rather than one single end-to-end project
- Topics include biomedical signals, skin cancer image analysis, sepsis modeling, and general medical ML experimentation
- Main outputs are notebooks, short reports, and assignment write-ups

## What this folder contains
- `Assignment_1_signals/`: ECG signal classification assignment with added model comparison and evaluation metrics
- `Assignment_2_skin_cancer/`: skin lesion dataset exploration and PH2 data loader preparation
- `Assignment_3_predictions/`: prediction-related coursework notebook
- `ecg.ipynb`: ECG modeling experiments
- `sepsis.ipynb`: sepsis-related notebook
- `skin_cancer_classification.ipynb`: skin cancer classification work
- `Melanoma_Identification_2020.ipynb`: melanoma-related notebook and report

## Topics covered
- ECG signal classification and model comparison
- Additional evaluation metrics for imbalanced medical classification tasks
- Skin lesion dataset exploration and bias assessment
- Data preparation for dermoscopy classification datasets
- Medical image classification experiments
- Sepsis-related machine learning workflow

## Notes
- This folder is kept as coursework archive material and is not actively maintained
- Large datasets, checkpoints, and generated artifacts should not be committed in a public portfolio version
- The strongest parts of this folder are the reports and a few representative notebooks, not the full raw course workspace

Coursework from an applied machine learning in medicine module during my studies.
