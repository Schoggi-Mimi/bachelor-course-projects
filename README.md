# Bachelor Course Projects Archive

This repository is an archive of selected coursework from my bachelor studies in Artificial Intelligence and Machine Learning. It contains smaller projects from different modules and shows the range of topics I worked on during my degree.

## What is included
- `ai_challenge/`: RNA structure prediction project for the Stanford Ribonanza Kaggle challenge
- `aml_med/`: applied machine learning in medicine coursework, including ECG classification, skin lesion analysis, sepsis-related experiments, and medical ML notebooks
- `data_visualization/`: interactive visual story about indoor air quality and office performance
- `database_systems/`: relational database and Streamlit dashboard for analyzing life expectancy, drinking water access, and infant mortality
- `natural_language_processing/`: ARC multiple-choice reasoning project with word embeddings, BERT models, and LLM evaluation
- `web_technologie/`: educational RSA encryption website built with HTML, CSS, JavaScript, PHP, and SQL

## Notes
- These folders are kept as coursework archive projects and are not actively maintained
- Some projects were completed individually and others in teams
- The code and reports are preserved to document the methods, tools, and project structure used at the time
- My more polished and recruiter-facing projects are available in separate repositories on my GitHub profile

## Purpose of this repository
This repository is meant to show breadth across machine learning, NLP, databases, visualization, and web development during my bachelor studies. It is best viewed as supporting background material rather than as a collection of flagship portfolio projects.
